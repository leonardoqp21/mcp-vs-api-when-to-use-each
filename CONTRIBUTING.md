# Contributing

- **A definition or claim is wrong:** open a pull request with the correction and a source.
- **A new example:** add a row to `docs/examples.md` and, if it clarifies a rule, a case in `code/decide/cases.json` with its expected result.
- **The protocol changed:** update `code/demo/mcp_server.py` and `docs/glossary.md`, and say which protocol revision you checked.
- Keep the guide vendor-neutral outside `docs/stacksync-mapping.md` and the short Stacksync section of the README.
- Describe behavior, not outcomes. No performance numbers you cannot source.
- Use synthetic data only.
